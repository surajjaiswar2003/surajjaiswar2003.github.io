    1. TA0043
      Reconnaissance
      
            
      Attacker
      Scans exposed services and harvests staff names and emails from public sources.
      
            
      Defence
      Map our own attack surface first. Run the same scans and OSINT sweeps before they do, then close what shouldn't be open.
      
            
      • Nmap
      • Nessus
      • OSINT
      2. 
          
    2. TA0001
      Initial access
      
            
      Attacker
      Sends a phishing email or exploits a weak spot in a web application.
      
            
      Defence
      VAPT against the OWASP Top 10, plus web filtering at the edge so a clicked link never reaches the payload.
      
            
      • Burp Suite
      • Acunetix
      • Zscaler ZIA
      3. 
          
    3. TA0002
      Execution
      
            
      Attacker
      Runs malware or a remote access tool on the compromised machine.
      
            
      Defence
      EDR on endpoints, IDS signatures on the wire, and malware analysis to learn what the sample actually does.
      
            
      • EDR
      • Snort
      • Malware analysis
      4. 
          
    4. TA0004
      Privilege escalation
      
            
      Attacker
      Hunts for admin credentials or a misconfiguration to become an administrator.
      
            
      Defence
      Least privilege by default. Zero Trust means a user only reaches the apps they need, never the whole network.
      
            
      • Zero Trust
      • ZPA
      • ZTNA

    5. TA0008
      Lateral movement
      
            
      Attacker
      Hops from the first machine toward the servers that hold the data.
      
            
      Defence
      Segment the network so east-west traffic has to cross a firewall, and alert on unusual internal connections.
      
            
      • Palo Alto
      • IDS/IPS
      • SASE
